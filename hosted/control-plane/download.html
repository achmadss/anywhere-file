Checking a download

SHA256SUMS lists a checksum for each file. Work out the checksum of the file you downloaded, with its name in place of FILE, and compare it with the line for that file. If they differ, delete the file and download it again.

  • macOS, in Terminal: shasum -a 256 FILE
  • Windows, in PowerShell: Get-FileHash FILE, or in a command prompt: certutil -hashfile FILE SHA256. PowerShell prints it in capitals, which makes no difference.
  • Linux: sha256sum -c SHA256SUMS --ignore-missing in the folder holding SHA256SUMS and the download
