# Spike reports

A spike answers one question that blocks a decision. It ends in a file here, whatever the
answer. A spike that reports "we cannot do this" has done its job and is the most valuable
kind.

Name files `<issue>-<slug>.md`. Keep them short and say four things: **the question**, **what
was tried**, **what happened** (numbers, error text, file and line references, evidence
somebody else can check), and **what it means for the plan** (which issues change, which
are now safe to start).

Expected here: #2 keystore, #3 mDNS, #4 Tauri shell, #42 path telemetry, #46 relay shaping
patch size.
